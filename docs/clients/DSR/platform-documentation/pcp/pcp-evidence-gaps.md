# PCP Evidence Gaps

## Purpose
List the unresolved questions that remain after repository review.

## Gaps
1. The Logic App workflow definition is not present.
2. The PCP import profile and queue allocation rules are not present.
3. PCP fundraiser screens and call-outcome handling are not present.
4. Closed-loop reconciliation back to Dataverse is not evidenced.
5. SFTP or other last-mile secure transfer into PCP is not evidenced.

## Why These Gaps Matter
The repository confirms the DSR export boundary, but support teams still need PCP-side confirmation to describe the full operational lifecycle.
