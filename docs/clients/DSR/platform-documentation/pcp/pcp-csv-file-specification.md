# PCP CSV File Specification

## Purpose
Describe the CSV structure produced by the PCP export flows.

## Confirmed Columns
| CSV Position | CSV Header | Business Meaning | Dataverse Table | Dataverse Column | Transformation | Required | Example Format | Validation Rule | Evidence |
|---|---|---|---|---|---|---|---|---|---|
| 1 | `ConstituentID` | supporter identifier | Contact / Account | `hit_constituentid` or `accountnumber` | copied | yes | synthetic text | required by export row | confirmed |
| 2 | `Organisation` | organisation name when applicable | Account | `name` | copied | no for contacts | synthetic text | blank for contacts | confirmed |
| 3 | `FullName` | supporter or primary contact name | Contact / Account | `fullname` or primary contact full name | copied | yes | synthetic text | may be blank for some organisations | confirmed |
| 4 | `Phone1` | primary phone number | Contact / Account | `mobilephone` or `telephone1` | spaces removed | preferred | digits only | no spaces in output | confirmed |
| 5 | `Phone2` | alternate phone number | Contact / Account | `telephone2` | spaces removed | no | digits only | no spaces in output | confirmed |
| 6 | `Phone3` | tertiary phone number | Contact / Account | `telephone1` or `telephone3` | spaces removed | no | digits only | no spaces in output | confirmed |
| 7 | `Email` | email address | Contact / Account | `emailaddress1` | copied | no | synthetic email | blank when absent | confirmed |
| 8 | `Location` | export geography | flow constant | n/a | fixed value `VIC` | yes | VIC | hard-coded in export flow | confirmed |
| 9 | `CRMUrl` | record link back to DSR | Contact / Account | record id | concatenated CRM URL | yes | URL text | built from base URL + record id | confirmed |

## File Naming
- Contact files: `YYYYMMDD_DSR_ActiveContacts.csv` and `YYYYMMDD_DSR_ProspectContacts.csv`.
- Organisation files: `YYYYMMDD_DSR_ActiveOrganisations.csv` and `YYYYMMDD_DSR_ProspectOrganisations.csv`.

## CSV Behaviour
- CSV content is generated by the Power Automate Table action.
- The repository confirms CSV output but does not separately specify delimiter, quote escaping, or line ending configuration.
