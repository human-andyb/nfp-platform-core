# PCP Current and Future State

## Purpose
Separate what is implemented now from ideas that are not confirmed in source.

## Current State
- DSR exports contact and organisation files for the PCP handoff.
- The current downstream boundary is SharePoint plus a Logic App invoke.
- PCP-side processing is not fully evidenced.

## Future State Ideas Not Implemented
- Direct API-based PCP integration.
- Closed-loop outcome synchronisation back to Dataverse.
- Fully evidenced queue allocation and reconciliation reporting.

## Decision Status
These future-state items are not confirmed as implemented. They remain proposals or possible improvements only.
